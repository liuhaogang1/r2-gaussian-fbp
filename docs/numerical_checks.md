# 数值正确性检查

运行成功、损失下降和图像看起来正常，都不能单独证明重建代码的数学实现正确。
目前也不能保证整个仓库没有其他问题；需要用可重复的独立检查逐步扩大覆盖。

## 本次体素化回归

先在用于训练的 Python 环境中，分别进入以下目录重新编译扩展：

```text
r2_gaussian/submodules/xray-gaussian-rasterization-voxelization
r2_gaussian/submodules/self-xray-gaussian-rasterization-voxelization
```

编译命令：

```text
python setup.py build_ext --inplace
```

Windows 需要已加载 MSVC 和 CUDA 的开发终端。重编译后启动新的 Python 进程。
只修改 CU 源码不会改变已经编译或已经载入的扩展。

在仓库根目录运行：

```text
python -m unittest discover -s tests -p test_voxelizer_gradients_cuda.py -v
```

该测试检查普通和 pose 两个后端：

- X/Y/Z 单层切片、三维块，不同且非等向的体素间距。
- 位置、密度、尺度、旋转参数的反向导数与各自前向有限差分的一致性。
- CUDA 内部计算协方差、Python 预计算协方差两条路径。
- 实际三维 TV 损失对 Gaussian 位置的导数。
- 扩展实际加载路径，防止误用另一份仓库的旧二进制。

CUDA 或扩展缺失时，测试会显示 SKIP。SKIP 表示未验证，不代表该路径通过。
发布训练环境应要求这两个后端的测试均实际执行。

## 分层检查

1. **导数检查**：对自定义 CUDA 或 autograd 算子，将反向传播与有限差分比较。
   检查位置、密度、尺度、旋转、相机位姿；选择避开裁剪边界和绝对值拐点的样本，
   合理设置扰动大小和数值容差，不能只检查梯度非零或没有 NaN。
2. **解析合成数据**：使用已知密度、尺寸、中心和方向的 Gaussian 或球体，
   独立生成解析投影。检查恢复的幅值、中心、尺寸和坐标方向；不能只用同一套
   可能有误的正反算子相互证明。
3. **不变量**：同步缩放几何和投影后密度尺度应保持一致；整块查询和分块导出应
   在同一网格上吻合；关闭可选功能时应回到基础路径。
4. **选项组合**：覆盖 TV、位姿、形状约束、预计算协方差的开关组合，以及非立方
   网格、非零原点、矩形探测器和不同采样分辨率。默认配置通过不能代表所有配置通过。
5. **小规模训练**：检查投影误差与结构误差能否同时改善，并验证增密、剪枝和
   checkpoint 恢复后的参数、优化器状态是否一致。

已有的相关检查入口包括：

```text
python scripts/validate_physical_projection.py --pose
python -m unittest discover -s tests -v
```

全套测试通过仅说明已覆盖的断言通过。遇到新的输入、选项或错误，应将最小复现例
加入回归测试，再修复实现，避免同类问题再次出现。

## 修复后的训练解释

体素化位置梯度修复会改变 TV 对 Gaussian 位置的实际作用。旧 checkpoint 的模型值
不会被重编译自动更改；相同模型的前向密度也不会因本次位置反向修复而自动改变。
评估训练收益时应以相同初始化重新做小规模对照，不能只重新导出旧 checkpoint。
